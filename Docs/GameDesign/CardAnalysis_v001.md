## 一、玩家英雄卡

### CARD_001 — 刘备

| 属性 | 值 |
|---|---|
| 费用 | 1 |
| 类型 | Hero / Leader |
| HP / ATK | 8 / 8 |
| 阵营 | Player / Shu |
| 稀有度 | Rare (唯一 1 张) |
| 技能 | 昭烈仁德 (EFFECT_LB_001) |

**技能详解**

- 触发时机：OnTurnStart
- 效果：GainMaxHpAndRevival
- 目标：AllyAllSameRow (同排全体友方)
- 数值：最大生命 +1 并恢复 1 点生命，获得 3 层复苏

**机制分析**

1. 每回合为同排所有友方 +1 最大血量 + 治疗 1 + 3 层复苏，是持续性增益核心。
2. 复苏在回合末触发：每层恢复 `1 + RevivalHealBonusPerStack` 点生命后消耗 1 层。遗物「太平符」可令玩家侧复苏 +1 /层。
3. 刘备 + 多个低血单位同排站位时，复苏叠层非常快，形成**堆叠回复流**。
4. 费用仅 1，ATK 8 在 Hero 中与关羽并列最高，定位为"Leader"却同时输出拉满。

**潜在问题**

| 编号 | 描述 |
|---|---|
| P1 | 3 层复苏/回合 × 同排最多 5 单位 = 15 层复苏/回合，加上本身最大血量累积，后期几乎不死。建议考虑单位上限或复苏层数上限。 |
| P2 | AllyAllSameRow 包含自身，因此刘备也给自己加 MaxHp 和复苏。多回合后数值极度膨胀。 |
| P3 | 作为唯一 lord 卡 (Lord = CARD_001)，死亡不触发直接失败，仅是普通单位阵亡逻辑。设计意图上是否应有特殊地位？ |

**与遗物联动**

- 太平符 (RELIC_003)：RevivalHealBonusPerStack +1 → 复苏每层回 2 HP，与刘备叠复苏形成超强 combo。

### CARD_002 — 关羽

| 属性 | 值 |
|---|---|
| 费用 | 2 |
| 类型 | Hero / Duelist |
| HP / ATK | 8 / 8 |
| 阵营 | Player / Shu |
| 技能 | 武圣 (EFFECT_GY_001) |

**技能详解**

- 触发时机：OnAttack
- 效果：BonusDamage
- 目标：CurrentTarget
- 数值：额外造成 2 点伤害

**机制分析**

1. 代码路径：`ResolveUnitAttack` → 先执行攻击本身 (8 伤害) → 再 `TriggerEffects(attacker, "OnAttack", …)`，此时对同一 target 额外造成 2 点，合计单回合 **10 点有效伤害**。
2. 注意：ReplaceAttack 优先级高于 OnAttack。若关羽同时拥有 ReplaceAttack 效果，则 OnAttack 不触发 (因 `TryResolveReplaceAttack` 返回 true 后跳过后续)。
3. BonusDamage 额外伤害也走 `DealDamage`，因此也会被护盾 / 护甲 / 免疫 / DamageCap 影响。
4. 额外伤害触发 OnDamaged 效果 (如夏侯惇的刚烈)。

**潜在问题**

| 编号 | 描述 |
|---|---|
| P1 | 额外伤害 2 点是固定值，无法成长。中后期面对高护甲 Boss 可能收益递减。 |
| P2 | BonusDamage 与护盾交互（已核实代码）：`ResolveUnitAttack` 中 `DealDamage`(主攻击) 的 `return` 只退出 `DealDamage`，**第 380 行 `TriggerEffects(attacker, "OnAttack")` 仍会执行**。所以主攻击被护盾挡住后，武圣的额外 2 伤害仍会触发，并独立走一次 `DealDamage`。**结论：关羽打有护盾的目标时——主攻击消耗第 1 层护盾（0 HP 伤害），随后额外 2 伤害再结算：若目标仅 1 层护盾则 2 伤害生效，若有 ≥2 层则再消耗 1 层护盾。即一次攻击可消耗目标 2 层护盾。** |

- 效果：GainThorns

| P2 | 荆棘反伤不走 source 方护盾/护甲检测 (DealDamage source=null)，不触发 Thorns (避免无限循环 — 已正确处理)。 |

### CARD_012 — 马超

| 属性 | 值 |
|---|---|
| 费用 | 2 |
| 类型 | Hero / Cleave |
| HP / ATK | 9 / 2 |
| 阵营 | Player / Shu |
| 技能 | 铁骑横扫 (EFFECT_MC_001) |

**技能详解**

- 触发时机：OnAttack
- 效果：ReplaceAttack
- 目标：EnemyAllSameRow
- 数值：对同排所有敌方单位造成 2 点伤害

**机制分析**

1. **ReplaceAttack 完全替代普通攻击**。马超不执行单体 9ATK 攻击，而是对同排所有敌人各造成 2 点伤害。
2. 代码逻辑：`TryResolveReplaceAttack` → 找到 effect → `ResolveTargets(EnemyAllSameRow)` → 对每个活着的敌方单位各 DealDamage 2。
3. ATK 属性 (2) 实际上通过 effect.Value 体现而非 card.Attack (9)。**存在数据矛盾**：csv 中 Attack=2 但 CardRecord.Attack 来自 Unit.Attack，UI 显示 ATK=2。代码里 ReplaceAttack 用的是 effect.Value=2，不是 unit.Attack。

**潜在问题**

| 编号 | 描述 |
|---|---|
| P1 | units_v001.csv 中 Attack=2，effect Value=2，一致。但 HP=9 偏低 (没有护甲/复苏/荆棘)，2 费且 AOE 仅 2 点。且 ReplaceAttack 走的是普通攻击渠道 (source=马超)，**会被护甲/护盾完整抵消**。面对张梁 (8 点护甲) 及其同排 +3 护甲的护卫，马超几乎零贡献。 |
| P2 | ReplaceAttack 不触发后续 OnAttack 其它效果 (代码在 TryResolveReplaceAttack return true 后跳过 TriggerEffects)。如果给马超装备叠加 OnAttack BonusDamage 类效果，不会生效。 |
| P3 | 敌方同排如果没有单位，TryResolveReplaceAttack 返回 true 且 targets.Count==0 直接返回 → 马超本回合什么都不做。不够直观。 |
| P4 | **ReplaceAttack 使用 `effect.Value`(固定 2) 而非 `unit.CurrentAttack`**。因此强化 (PLAN_004 +2 ATK)、曹操式加攻、任何 BuffAttack 对马超完全无效。马超是卡池中**唯一无法成长的单位**，也使其 ATK=2 属性成为纯展示数据。建议改为以 `attacker.Attack` 作为 AOE 伤害。 |

| HP / ATK | 7 / 6 |

## 四、计谋牌

### PLAN_001 — 滚石

| 费用 | 1 | 效果 | 对单体敌人造成 3 点伤害 |
|---|---|---|---|
| TargetRule | EnemySingle | EffectType | Damage |

**分析**：1 费 3 伤害，基本去除牌。可精准斩杀 HP≤3 的单位（骑兵 3HP、弓箭手 2HP）。

## 六、系统级发现（跨卡牌的机制问题）

以下问题不属于单张卡，而是影响整体卡牌设计的系统级机制，**均已对照代码逐行核实**。

### S1 — 计谋牌伤害完全无视护甲与护盾（严重度：高）

`ResolveSkillCardEffects` 中所有伤害类分支调用的都是 `DealDamage(**null**, unit, ...)`，source 为 null。而 `DealDamage` 中三道防御都被 source 非空条件短路：

```csharp
if (source != null && source.Camp != target.Camp && target.TryConsumeShield())   // 跳过
if (source != null && source.Camp != target.Camp && target.TryConsumeAttackImmunity()) // 跳过
var armorAbsorbed = source != null && source.Camp != target.Camp ? target.ConsumeArmor(...) : 0; // 永远为 0
```

**后果**：滚石、齐射、火攻、火箭、斩杀的**即时伤害全部是真实伤害**，既不消耗也不被护盾/护甲/免疫抵消。

这使得：
- 张梁的 8 点护甲、张宝/张角的护盾对计谋牌**完全无效**，“高护甲 Boss”的设计意图被架空。
- 计谋牌成为狙击 Boss 的唯一高效手段（叠加下述 S2 的前排保护机制，存在一定合理性，但强度失控）。
- 而 `ApplyBeforeDamagedEffects`（DamageCap）**不**受 source 限制，仍然生效 → 曹仁的固守会把计谋牌伤害截断到 4。同一组防御机制中部分生效部分不生效，**规则不一致**。

建议：为计谋牌引入一个虚拟施法者阵营（或给 `DealDamage` 增加 `ignoreDefenses` 显式参数），使“是否穿透防御”成为可配置的卡牌属性而非隐式副作用。

### S2 — 护甲与荆棘永不衰减，无上限累积（严重度：高）

`ResolveEndOfTurnBuffs` 仅处理 **Burn**（衰减 1）和 **Revival**（消耗 1）。**Armor 和 Thorns 没有任何衰减逻辑**。

| 卡牌 | 累积速度 | 第 5 回合数值 |
|---|---|---|
| 赵云龙胆 | +5 护甲/回合开始 | 未被打时高达 25 护甲 |
| 张飞据水断桥 | +2 荆棘/回合结束 | 10 层荆棘（配铁蒺藜后翻倍至 20 点/次） |

后期敌人攻击张飞将**因荆棘反伤直接致死**，形成“站着不动自动胜利”。建议：护甲改为回合末清零或衰减，荆棘设层数上限。

### S3 — 开局手牌与第一手完全确定，零决策空间（严重度：中）

`BattleDeck.DrawInitialHand` 优先抽取**所有**英雄牌：

```csharp
var heroCards = state.DrawPile.Where(c => c.CardType == Unit && c.UnitType == Hero && c.Camp == Player)
```

初始牌库恰好有 3 张英雄（刘备/关羽/张飞），initialHandSize=5 → heroCount=min(5,3)=3 → **三张英雄 100% 必在开局手牌**。

而准备阶段费用恰为 5，三英雄总费用 = 1+2+2 = **恰好 5**。

**后果**：每局开场的最优解完全相同（三英雄全上），准备阶段没有任何决策。肉鸽游戏最重要的开局变异性完全缺失。

### S4 — 回合末弃光全部手牌，严重贬值所有过牌（严重度：高）

`ResolvePlayerTurnRoutine` 开头即调用 `DiscardHand(logLines)` → 手牌**全部**进弃牌堆，不保留。

叠加正式回合仅 3 费的限制，导致：

| 卡牌 | 名义效果 | 实际价值 |
|---|---|---|
| 简雍（每回合抽 1） | 过牌引擎 | 多抽的牌无费用可打，回合末直接弃掉 |
| 草船借箭（1 费抽 2） | 牌差 +1 | 花 1/3 费用换两张打不出的牌，**净负收益** |
| 铁甲军令（遗物） | 首张单位牌抽 1 | 同样被弃牌抵消 |

**根本矛盾**：当费用（3）而非手牌数量是真正的约束条件时，所有过牌效果都是无效的。前文将简雍评为 A、草船借箭评为 B+ **偏乐观**，在当前规则下应分别下调至 **C+ / C**。

建议：改为保留手牌（设上限），或为过牌牌同时附带费用返还。

### S5 — 骑兵严格强于弓箭手（严重度：中）

| 卡牌 | 费用 | HP | ATK |
|---|---|---|---|
| CARD_005 弓箭手 | 1 | 2 | 6 |
| CARD_010 骑兵 | 1 | **3** | **7** |

同费用下骑兵 HP 和 ATK **双项均更优**，且两者都无技能、都是 Neutral 可上阵。弓箭手是被严格支配（strictly dominated）的废牌。

而初始牌库给了玩家 3 张**较弱的**弓箭手，骑兵只能从奖励获得。同理，**赵云（15/10/+5护甲）也几乎严格强于关羽（8/8/+2伤）**，同为 2 费。建议差异化而非单线提升数值。

### S6 — CSV 中 `turn_index` 与 `spawn_timing` 是死字段（严重度：中）

`battle_001_waves_v001.csv` 定义了 `turn_index` 和 `spawn_timing`，`PrototypeCsvDatabase` 也确实解析到了 `WaveSpawnRecord.TurnIndex` / `SpawnTiming`，**但全仓库无任何代码读取这两个字段**。

`SpawnCurrentWave` 仅按 `state.NextWaveIndex++` 逐回合顺序出波。因此：
- 想设计“第 2 回合同时出两波”或“延迟出波”目前**无法实现**。
- 配表人修改 `turn_index` 会错误地以为生效，形成隐形坑。

### S7 — 魏国三张 Boss 牌为完全未使用内容（严重度：低）

CARD_006 曹操、CARD_007 夏侯惇、CARD_008 曹仁 已完成完整配置和技能实现，但**在 `battle_001_waves_v001.csv` 的任何一波中都未出现**。当前波次仅使用 CARD_004/005/009/010/014/015/016。

所以本报告中关于这三张卡的分析均为**纯代码推导，未经实战验证**。

### S8 — 敌方 OnTurnEnd 永不触发（潜在 Bug，严重度：低）

代码中有 `TriggerPlayerTurnStartEffects` / `TriggerEnemyTurnStartEffects` / `TriggerPlayerTurnEndEffects`，**但没有 `TriggerEnemyTurnEndEffects`**。

目前无敌方单位使用 OnTurnEnd，所以尚未暴露。但一旦未来给敌方 Boss 配置 OnTurnEnd 技能（例如敌方版据水断桥），**会静默失效**。

### S9 — 灼烧先于复苏结算，复苏无法救下灼烧致死（设计确认点）

`ResolveEndOfTurnBuffs` 先 Burn 后 Revival，且 Revival 分支条件为 `unit.Revival > 0 && !unit.IsDead`。

所以当灼烧伤害刚好致死时，**同一回合的复苏不会生效**。这使得：
- 张宝/张角的灼烧对刘备复苏流是硬克制（可能是好设计）。
- 但玩家缺乏预知手段，体验上容易因“明明有复苏却死了”而困惑。建议 UI 明确提示结算顺序。

### S10 — 张梁护甲可能双重结算（待确认）

`FortifySameRowAndSelf` 先对 `ResolveTargets(AllyAllSameRow)` 全体加 3 护甲，**而 `AddRowTargets` 的 `excluded` 参数从未被传入**，因此张梁自己也包含在“同排”中 → 得 3 点；随后 `source.AddArmor(secondary=5)` 再得 5 点。

**张梁实际获得 8 点护甲，而非 5 点**。

CSV 描述为“同排敌方单位获得 3 点护甲，张梁**额外**获得 5 点护甲”——“额外”一词存在歧义：3+5=8 可能是意图，也可能是想要 5。**需设计者确认**。

## 八、建议优先改进项

### P0 — 影响玩法成立的机制修正

1. **修正计谋牌防御穿透（S1）**：为 `DealDamage` 增加显式 `ignoreDefenses` 参数，让“真实伤害”成为卡牌显式属性，而非 source=null 的隐式副作用。
2. **给护甲/荆棘加衰减或上限（S2）**：否则赵云与张飞在长局中无敌。
3. **重构手牌保留规则（S4）**：当前全弃牌使整个过牌子系统（简雍、草船借箭、铁甲军令）失去意义。
4. **打破开局确定性（S3）**：取消英雄优先抽牌，或让准备阶段费用不恰好等于三英雄总和。

### P1 — 数值与卡牌质量

5. **消除严格支配关系（S5）**：弓箭手需差异化（如赋予跨排/后排攻击能力，兼顾其 Ranged 标签）；关羽需差异化或赵云降数值。
6. **弱牌加强**：齐射→ 2 伤害或 0 费；斩杀→ 改为“对 HP 低于阈值的单位直接消灭”才符合命名。
7. **修复马超无法成长（P4）**：ReplaceAttack 改用 `attacker.Attack` 而非 `effect.Value`，否则马超永远是 2 点 AOE。
8. **刘备复苏设上限**：避免同排多单位时每回合 15 层复苏的无限续航。

### P2 — 工程与配置健康

9. **清理或启用死字段（S6）**：要么实现 `turn_index`/`spawn_timing`，要么从 CSV 中删除，避免配表陷阱。
10. **补上 `TriggerEnemyTurnEndEffects`（S8）**：防止未来敌方 OnTurnEnd 技能静默失效。
11. **接入魏国三 Boss 或标记为未启用（S7）**：避免已完成内容长期闲置。

## 十、卡牌设计合理性评分

评分日期：2026-08-18

### 评分标准

满分 10 分，由五个维度加权构成。**评分针对"设计合理性"，不是"强度"** —— 一张过强的卡会因破坏平衡而扣分，一张弱卡也会因缺乏使用场景而扣分。

| 维度 | 权重 | 说明 |
|---|---|---|
| 数值合理性 | 2.5 | 费用与身板/效果是否匹配，是否与同费卡横向自洽 |
| 机制清晰度 | 2.0 | 玩家能否直观理解效果，行为是否符合卡面与命名预期 |
| 策略深度 | 2.5 | 是否创造有意义的决策（出牌时机、站位、目标选择） |
| 实现完备性 | 1.5 | 代码是否完整交付设计意图，有无死数据/静默失效 |
| 定位差异化 | 1.5 | 是否与其它卡形成区分，有无被严格支配 |

评级对照：**9-10 优秀** / **7-8 良好** / **5-6 可用待调** / **3-4 存在明显问题** / **0-2 需重做**

#### CARD_003 张飞 — 8.1 分（良好）

**加分**：据水断桥的反伤机制与"独守长坂桥"的历史意象高度契合，是全卡池**主题与机制结合最好的一张**。20/5 的身板明确传达"肉盾"定位，与赵云的护甲减伤形成两条不同的防御路线（反伤 vs 减伤），差异化成立。反伤创造了"是否让敌人攻击张飞"这一敌方层面的博弈。

**扣分**：实现项扣 0.5 —— 反伤层数无衰减无上限（S2），第 5 回合 10 层、配遗物后达 20 点/次，长局会形成"站着不动自动胜利"。深度扣 0.7 —— 层数是纯被动累积，玩家除站位外无操作介入空间。

#### CARD_002 关羽 — 6.6 分（可用待调）

**加分**：机制维度满分。武圣的 OnAttack +2 是最容易理解的效果，无任何歧义，8/8 身板与"斩将"定位一致。

**扣分**：数值仅 1.3、差异化仅 0.7 —— 这是**全卡池最严重的横向失衡**。同为 2 费，赵云 15/10/+5甲 在身板和技能上双项碾压关羽 8/8/+2伤；而 1 费的刘备同样是 8/8 身板且技能更强。关羽处于**被两张卡同时支配**的位置。深度扣分是因为固定 +2 不随游戏进程成长，中后期收益递减。

#### CARD_001 刘备 — 6.6 分（可用待调）

**加分**：昭烈仁德的全排增益建立了"堆叠回复流"这一完整构筑方向，配合太平符形成清晰的 combo 路径，策略深度 1.6 是玩家单位中较高的。Rare + max_copies=1 的唯一性处理正确。

**扣分**：数值维度仅 0.6，是**全卡池最低**。1 费获得 8/8 身板（等于 2 费关羽）**再加**全游戏最强的持续增益，费用与价值完全脱钩。同排 5 单位时每回合产出 15 层复苏 + 5 点最大生命，无任何上限。清晰度扣分：AllyAllSameRow 包含自身，玩家不易预期自己也在增益范围内。

**核心建议**：费用改为 2，或将复苏层数从 3 降至 1。

#### CARD_013 简雍 — 6.0 分（可用待调）

**加分**：差异化 1.5 满分 —— 全卡池**唯一的非战斗功能型英雄**，2/2 身板明确表达"文士不参战"，论客与抽牌的对应关系贴切。1 费 + 高风险高收益的定位在肉鸽中是标准且优秀的设计思路。

**扣分**：实现仅 0.4 —— 这是**设计意图被系统架空的典型案例**。因回合末全弃手牌（S4）且正式回合仅 3 费，多抽的牌既打不出也留不住，简雍的核心价值当前**接近于零**。深度扣分同理：本应是过牌引擎，实际不产生任何决策。

**注意**：这张卡的低分**不是卡牌本身的问题**，修复 S4 后可直接升至 8 分区间。

#### CARD_011 赵云 — 5.9 分（可用待调）

**加分**：机制清晰（每回合固定 5 护甲），实现正确（GainArmor 目标为 Self，未犯全排增益的错误）。

**扣分**：数值 0.7 —— 2 费同时拥有次高血量（15）、**全卡池最高攻击（10）**、以及稳定减伤，三项全能。定位矛盾：role=Guard 却是攻击力最高的单位，卡面身份与实际功能不符（清晰度扣 0.1，定位扣 0.6）。护甲无衰减（S2）导致未被攻击时可累积至 25 点。

**核心建议**：护甲降至 3，或 ATK 降至 7；并让护甲在回合末清零。

#### CARD_012 马超 — 4.9 分（存在明显问题）

**加分**：填补了 AOE 横扫的空白生态位，铁骑横扫与骑将身份契合，差异化 1.4。

**扣分**：实现仅 0.3，全卡池最低。三项叠加缺陷：

1. ReplaceAttack 读 `effect.Value`（固定 2）而非 `unit.CurrentAttack` → **卡池中唯一无法被强化的单位**，ATK=2 属性成为纯展示的死数据。
2. 走普通攻击渠道，被护甲/护盾完整抵消 → 面对张梁（8 护甲）及 +3 护甲护卫时**贡献为零**。
3. 敌方同排为空时静默空过，无 fallback 也无提示。

清晰度扣 0.8：玩家用强化牌给马超 +2 ATK 后**毫无变化**，这是直接违反玩家预期的行为。

#### CARD_008 曹仁 — 9.3 分（优秀，全卡池最高）

固守（单次伤害上限 4）是**本卡池设计水平最高的一个效果**：

- **策略深度 2.4（最高）**：它不是简单加数值，而是**改变了玩家的最优解结构** —— 面对曹仁，10 攻的赵云（被截断至 4）反而劣于多个低攻单位的多段攻击。这迫使玩家重新配置阵容，是真正的"解谜型"敌人。
- **教学价值**：天然引导玩家理解"单次伤害 vs 攻击次数"的概念。
- **实现稳健**：ApplyBeforeDamagedEffects 不受 source 限制，因此它是**唯一对计谋牌真实伤害也生效的防御机制**（S1），意外地成为设计最鲁棒的一张。

扣分：清晰度 -0.1（伤害上限与护甲的结算先后顺序玩家不可见）；数值与实现各扣少量，因其从未在任何波次出现（S7），实战表现未经验证。

#### CARD_015 张宝 — 8.6 分（优秀）

三张黄巾 Boss 中**设计最好的一张**。地公妖火的 3 层灼烧创造了明确的**时间压力与反制窗口**：玩家看到灼烧后必须在本回合内决策（用加固挡、用疗伤补、或撤走低血单位）。10 HP 的低血量与 Caster 定位一致 —— 输出威胁大但自身脆，符合"法系"直觉。同时它是对刘备复苏流的针对性克制（灼烧先于复苏结算，S9），生态位价值高。

扣分：清晰度 -0.2，S9 的结算顺序（灼烧致死时复苏不生效）玩家无法预知，容易产生"明明有复苏却死了"的困惑，需要 UI 提示。

#### CARD_006 曹操 — 8.4 分（良好）

魏武号令的 OnPlay 全排 +1 ATK 是**教科书式的 Leader 设计**：价值与登场时机强相关（越早、同波单位越多则收益越高），这为敌方波次编排提供了真实的设计杠杆。机制清晰，与 Leader 身份契合。扣分主要在于从未被任何波次使用（S7），设计价值处于闲置状态。

#### CARD_007 夏侯惇 — 8.3 分（良好）

刚烈（受击 +1 ATK）创造了优秀的**递增威胁张力** —— "快速集火击杀，否则越打越痛"，这是能自然产生紧张感的设计，策略深度 2.2 很高。

扣分集中在实现一致性（1.0）与清晰度（1.6）：

- 灼烧伤害走 TakeDamage **不触发 OnDamaged** → 灼烧打夏侯惇不加攻，但玩家无从得知这个区别。
- 关羽的 BonusDamage 独立走一次 DealDamage → **一次攻击触发 2 次刚烈（+2 ATK）**。

这两条都属于"同类行为结果不同"，需明确并统一。

#### CARD_016 张角 — 6.7 分（可用待调）

**加分**：终局 Boss 的多重机制（全军复苏 + 自身护盾 + 每回合灼烧）层次感足够，40 HP 的压迫感与"太平道教主"身份匹配，差异化 1.4。

**扣分**：数值 1.3 / 深度 1.2 —— **40 HP + 2 护盾 + 全军持续回血，但 ATK 仅 3**。这个组合产生的是"血条很长但威胁很低"的体验：玩家不会死，只是需要磨很久。终局 Boss 缺乏威胁意味着**紧张感由耐心取代**，这是节奏设计上的问题。另有可规避性缺陷：OnTurnStart 灼烧仅作用于同排，玩家避开中军即可完全规避。

**核心建议**：降低 HP 至 25-30 并提升 ATK，或引入阶段转换机制，用"变化"而非"血量"承载终局感。

#### CARD_014 张梁 — 6.1 分（可用待调）

**扣分**：策略深度 0.8 是**全卡池最低**。25 HP + 8 点护甲 + ATK 3 = **纯粹的血量检查（stat check）**，不提供任何需要玩家思考或改变打法的元素，只是延长战斗时长。作为玩家遭遇的**第一个 Boss**，这一点尤其可惜 —— 首个 Boss 最应该教会玩家某个机制。

实现扣 0.5：AddRowTargets 的 excluded 参数未传入，张梁实得 3+5=8 点护甲而非 5 点（S10），设计意图待确认；且其护甲被计谋牌真实伤害完全无视（S1），"高护甲 Boss"的设计承诺在实际玩法中不成立。

#### PLAN_005 加固 — 9.2 分（优秀，计谋牌最高）

**策略深度 2.3** 是计谋牌最高。原因：1 层护盾**完全抵挡一次攻击且不论伤害大小**，这创造了一个纯粹的时机博弈 —— 挡张角的 3 点是浪费，挡赵云级别的 10 点则是巨大收益。玩家必须预判敌方行动来决定何时使用，这是**高质量的决策**。1 费的定价让它在任何阶段都是活牌。

扣分：实现 1.3 —— 护盾无持续时间限制，且能抵挡灼烧，实际强度偏高，可考虑限定为"下回合结束前有效"。

#### PLAN_006 火攻 — 8.7 分（良好）

3 即时 + 2 层灼烧（跨 2 回合共 3 点）的结构清晰，2 费对比滚石 1 费 3 伤，多付 1 费换取 3 点**分期伤害**，形成了"即时 vs 持续"的真实取舍。有趣之处：灼烧部分会被护甲吸收而即时部分不会（S1），意外地让这张卡对高护甲目标产生了"部分穿透"的层次感。

扣分：清晰度 1.8 —— 同一张卡的两段伤害走不同防御规则，玩家不可能推断出来。

#### PLAN_003 疗伤 — 8.6 分（良好）

即时治疗 2 + 2 层复苏的双段结构很好：既能应急救命，也能作为前置铺垫，用途覆盖广。1 费定价合理，作为初始牌库的唯一治疗手段承担了必要的容错功能。扣分：与刘备的复苏产生功能重叠（差异 1.3）。

#### PLAN_001 滚石 — 8.1 分（良好）

1 费 3 伤是干净的基准去除牌，能精准斩杀骑兵（3 HP）、弓箭手（2 HP），定位明确，是卡池的伤害标尺。扣分：清晰度 1.7 / 实现 1.2 —— 它实际是**无视护甲护盾的真实伤害**（S1），这个强力特性**卡面完全没有体现**，属于隐式副作用而非设计声明。

#### PLAN_007 火箭 — 8.0 分（良好）

AOE 版火攻，价值随敌方数量放大（满排 5 人时总期望伤害可达 30 点），是清兵的核心答案，与火攻形成"单体 vs 群体"的清晰分工。扣分：数值 1.8 —— 对 5 个 HP=2 单位一张全灭，强度上限偏高；清晰度同火攻问题。

#### PLAN_004 强化 — 7.3 分（良好）

**加分**：机制 2.0 满分，永久 +2/+2 是肉鸽中标准且令人满足的成长性设计，为构筑提供长期收益。

**扣分**：深度 1.3 / 数值 1.5 —— 1 费永久 +2 ATK +2 MaxHP **给任何单位用都是正收益**，除"该给谁用"之外不存在其它判断，缺乏取舍。**无条件强力 = 低决策密度**。另外它是马超无法享受的成长手段（实现 1.2）。

#### PLAN_002 齐射 — 5.6 分（可用待调）

机制清晰（1.9），但**数值 0.9 / 深度 0.8**：1 费换整排各 1 点伤害，绝对值过低。即便享有无视护甲的特性，1 点伤害也仅在敌方整排恰好剩 1 HP 时有意义，使用窗口极窄。与火箭（2 费整排 1 伤 + 2 灼烧）相比性价比明显偏低，差异化 0.8。

**建议**：提升至 2 点伤害，或改为 0 费。

#### PLAN_009 草船借箭 — 5.4 分（可用待调）

机制 2.0 满分，1 费抽 2 是经过验证的标准过牌设计（对标《杀戮尖塔》的 Acrobatics）。

**扣分**：实现 0.4 / 深度 0.7 —— 与简雍同因。在"回合末全弃手牌（S4）+ 正式回合仅 3 费"的规则下，花掉 1/3 的回合费用换取两张**打不出且留不住**的牌，是**净负收益**。这张卡在当前系统中不应该被玩家选取。

**注意**：同简雍，低分源于系统而非卡牌本身，修复 S4 后可回升至 8 分区间。

#### PLAN_008 斩杀 — 4.3 分（存在明显问题，全卡池最低）

**清晰度 0.6 / 深度 0.6，两项均为全卡池最低**：

1. **名实严重不符**：名为"斩杀"，玩家会预期"处决残血单位"（即斩杀线机制），实际是"造成 1 点伤害，若因此击杀则返还 1 费"—— 这是**补刀**，不是斩杀。命名直接误导玩家。
2. **触发窗口几乎不存在**：需目标当前 HP **恰好为 1** 才能返费。
3. **信息不对称使其无法规划**：敌方先行动，玩家在出牌时无法预知敌方血量分布，因此这张卡的核心机制**不可主动运用**，只能靠偶然。

实现维度 1.3 是唯一亮点 —— `wasAlive && unit.IsDead` 的双重检查逻辑正确，复苏不会干扰击杀判定。

**建议**：改为真正的斩杀线机制（"对 HP 低于上限 X% 的单位直接消灭"），使命名、机制、玩家预期三者统一。

### 六、评分揭示的三个结构性结论

#### 结论一：敌方卡设计水平系统性高于玩家卡（7.9 vs 6.4）

这是最反直觉也最重要的发现。曹仁的固守、张宝的妖火、夏侯惇的刚烈都做到了"**改变玩家的最优解**"，而玩家侧的刘备/赵云/关羽本质上都是"**加数值**"。

**玩家英雄的技能缺乏"改变战场规则"的维度** —— 全部是自我增益或直接输出，没有一张会让敌方行为或结算规则发生变化。这也解释了为什么玩家侧同时存在严重的横向失衡（刘备/赵云/关羽三角）：当卡牌之间只有数值差异而无机制差异时，**必然产生支配关系**。

#### 结论二：低分卡分两类，修复成本天差地别

| 类型 | 卡牌 | 修复方式 |
|---|---|---|
| **A. 系统连带受害**（卡本身设计合格） | 简雍 6.0、草船借箭 5.4 | 修复 S4（手牌保留规则）即可**同时**升至 8 分区间，**不需改动这两张卡** |
| **B. 卡牌自身缺陷** | 斩杀 4.3、弓箭手 4.5、马超 4.9 | 必须逐张重做机制 |

这个区分很关键：**先修 S4，能一次性提升两张卡且零卡牌改动成本**，投入产出比远高于逐卡调整。

#### 结论三：香草卡证明了"简单即合理"

刀兵（8.8）、盾牌兵（8.6）两张**无技能**卡的得分高于所有玩家英雄。原因是它们在数值曲线上站得住、零理解成本、零实现风险。

这反过来说明：**当前英雄卡的问题不是机制不够多，而是数值地基不稳**。在给卡池增加新机制之前，应先把 1 费 / 2 费的数值基准（以刀兵 6/4、盾牌兵 8/2 为锚点）定清楚，否则新卡会继续复制刘备/赵云式的失衡。

### 八、评分的可信度声明

| 维度 | 依据 | 可信度 |
|---|---|---|
| 实现完备性 | 逐行核实源码（S1–S10、V1–V9） | **高** —— 代码事实 |
| 数值合理性 | 直接读取 CSV 横向对比 | **高** —— 支配关系可数学证明 |
| 机制清晰度 | 代码行为 vs 卡面/命名预期比对 | **中高** —— 含主观判断 |
| 定位差异化 | 卡池内生态位比对 | **中高** |
| 策略深度 | 设计经验主观评估 | **中** —— 无实测对局数据 |

**总体**：分数的**相对排序**（谁比谁更需要改）可信度较高，因为主要由代码事实与数值支配关系驱动；**绝对分值含主观成分**，不宜作为验收标准。

所有涉及节奏与平衡的判断（张梁/张角的实际战斗时长、火箭的实际强度）**均未经实际对局验证** —— 项目当前无自动化测试、无 asmdef，无法在编辑器外运行验证，建议以实测数据复核。
