# Battle Prototype v001

## Game Type

三国题材、2D 横版、回合制、卡牌上阵、左右战线对抗。

## Board Layout

战斗主界面分为左右两侧：

- 左侧：玩家友方单位区域。
- 右侧：敌方单位区域。
- 底部：玩家手牌区域与结束回合按钮。
- 玩家大本营位于友方阵地上方居中位置，并展示生命值。

友方和敌方阵地均为 3 排 x 5 列的伪 2.5D 横向错位棋盘。

每一排独立结算前线：

- 友方单位从右向左排列，每排最右侧单位优先承伤。
- 敌方单位镜像布局，从左向右排列，每排最左侧单位优先承伤。
- 死亡结算后，友方每排向右补位，敌方每排向左补位。
- 玩家可以将手牌放入任意友方空格。
- 玩家可以在同一排的两个单位之间插入新单位，或在该排最右侧单位右边插入新单位。
- 不允许在两排之间插入单位。

## Card Data

当前卡牌数据拆分为：

- `cards_v001.csv`：卡牌通用信息，例如卡牌类型、费用、阵营、势力、稀有度、卡图 ID。
- `units_v001.csv`：单位牌信息，例如单位编号、英雄 / 普通兵种、血量、攻击力、角色定位、标签和技能效果 ID。
- `effects_v001.csv`：技能效果信息，例如触发时机、效果类型、目标规则和数值。
- `player_starting_deck_v001.csv`：玩家初始牌库，每行配置一张卡的初始数量与牌组规则。
- `battle_001_waves_v001.csv`：战斗波次配置，按关卡、波次和前中后军分别指定敌方单位。

当前卡牌类型包括：

- `Unit`：单位牌，玩家单位可以上阵到友方阵地，敌方单位通过波次生成。
- `Skill`：计谋牌，玩家点击手牌后进入施法状态，根据目标规则选择单位、整排或无目标立即释放。

## Unit Stats

当前单位包含：

- 血量
- 当前攻击力
- 费用
- 类型：英雄 / 普通兵种
- 阵营：友方 / 敌方
- 技能效果
- 运行时状态：护盾、免疫攻击次数、复苏层数、攻击力变化、最大血量变化、单次伤害上限

当前英雄费用：

- 刘备：1
- 关羽：2
- 张飞：2
- 赵云：2
- 马超：2
- 简雍：1
- 曹操：2
- 夏侯惇：2
- 曹仁：2

伤害规则：

```text
若目标拥有护盾层数，先消耗 1 层护盾并取消本次敌方攻击
若目标拥有免疫攻击次数，先消耗 1 次免疫并取消本次伤害
若目标拥有单次伤害上限，则本次伤害不超过该上限
目标当前血量 -= 结算后的伤害
目标当前血量 <= 0 时死亡
```

当前计谋牌直接伤害以无来源伤害结算：会受到 `BeforeDamaged` 伤害上限影响，但不会消耗护盾 / 免疫攻击次数，也不会触发 `OnDamaged` 受击后效果。

复苏规则：

- 复苏是层数型 Buff。
- 回合战斗结算、死亡移除和补位完成后，存活单位若拥有复苏，则触发一次复苏。
- 每次触发时，按触发前复苏层数恢复生命，然后复苏层数减少 1。
- 单位已经死亡并被移出阵地时，不会触发复苏。

## Skill Rules

当前英雄技能采用第一版轻量触发机制：

- `OnPlay`：单位上阵或敌方波次生成时触发。
- `OnAttack`：单位攻击时触发。
- `BeforeDamaged`：单位受到伤害前触发，用于伤害修正。
- `OnDamaged`：单位受到伤害后触发。
- `OnTurnStart`：玩家正式回合开始时，对场上存活的玩家单位触发。

当前英雄技能：

- 刘备「仁德」：上阵时，治疗同排最前方友方 3 点。
- 关羽「武圣」：攻击时，对当前目标额外造成 2 点伤害。
- 张飞「咆哮」：受击时，反击攻击者 2 点伤害。
- 赵云「龙胆」：上阵时，获得 2 层护盾，每层可抵挡一次敌方攻击。
- 马超「铁骑横扫」：攻击替换为对敌方当前排所有单位造成 2 点伤害。
- 简雍「论客」：存活在场时，每个玩家正式回合开始额外抽 1 张牌。
- 曹操「魏武号令」：上阵时，同排所有友方单位攻击 +1。
- 夏侯惇「刚烈」：每次受击后，自身攻击力 +1。
- 曹仁「固守」：每次受到伤害时，最多只受到 4 点伤害。

单位 token 会显示状态短文本：

```text
攻+1  盾2  免1  复2  限4
```

## Plan Card Rules

当前计谋牌均为玩家 `Skill` 卡，费用为 1，释放后进入弃牌堆：

- 滚石：选择敌方单体，造成 3 点伤害。
- 齐射：选择敌方一整排，对该排所有敌方单位造成 1 点伤害。
- 疗伤：选择友方单体，恢复 2 点生命，并获得 2 层复苏。
- 强化：选择友方单体，攻击 +2，最大血量 +2，并恢复 2 点生命。
- 加固：选择友方单体，获得 1 层护盾。
- 斩杀：选择敌方单体，造成 1 点伤害；若该伤害直接击杀目标，获得 1 点当前可用费用。
- 草船借箭：无目标，立即抽 2 张牌。

计谋牌目标规则：

- `EnemySingle`：需要选择一个存活敌方单位。
- `EnemyRow`：需要选择一排至少有存活单位的敌方阵地。
- `AllySingle`：需要选择一个存活友方单位。
- `NoTarget`：不需要选择目标，点击后立即释放。

## Deck Rules

- 英雄卡在牌库中最多只能有 1 张。
- 普通兵种可以重复。
- 玩家初始牌库包含：刘备、关羽、张飞、赵云、马超、简雍各 1 张；盾牌兵、弓箭手各 5 张；滚石、齐射、疗伤、强化、加固、斩杀、草船借箭各 1 张。
- 初始回合抽 5 张牌。
- 初始手牌优先从英雄卡库中随机抽取英雄卡。
- 当英雄卡数量大于 5 张时，随机选择 5 张英雄卡进入初始手牌。
- 当英雄卡数量小于或等于 5 张时，所有英雄卡进入初始手牌，剩余手牌位从抽牌堆补足。
- 初始回合结束时，未使用的手牌进入弃牌堆；抽牌堆中剩余的英雄卡也进入弃牌堆。
- 后续回合每回合抽 3 张牌，不再触发英雄卡必定进入手牌的规则。

## Turn Flow

```text
InitialPrepare
  玩家抽到 5 张初始手牌，英雄卡优先进入手牌
  玩家初始准备回合拥有 5 点费用
  玩家可以出牌

PrepareEnd
  玩家点击结束回合，准备阶段结束并进入第 1 回合

TurnStart
  当前回合对应敌方波次出现
  敌方单位站场，但不触发攻击
  玩家费用恢复到 3 点，抽 3 张牌
  场上存活的玩家单位触发 OnTurnStart 效果
  玩家继续操作，可以上阵单位或释放计谋牌

PlayerEndTurn
  玩家点击结束回合，进入战斗结算

EnemyAttack
  敌方按排从左到右依次攻击，每个单位攻击一次
  优先攻击同排最右侧友方单位；同排没有友方单位时攻击玩家大本营
  攻击过程中会结算相关技能、护盾、免疫和伤害上限

PlayerAttack
  友方按排从右到左依次攻击，每个单位攻击一次
  优先攻击同排最左侧敌方单位；同排没有敌方单位时不造成伤害
  攻击过程中会结算相关技能、护盾、免疫和伤害上限

TurnResolve
  结算死亡与胜负
  存活单位结算回合结束型 Buff，例如复苏

NextTurn
  进入下一回合的 TurnStart
```

## Level Rules

当前原型支持关卡概念，每个关卡包含 3 波敌人。

### 第 1 关

沿用已有波次，敌人默认出现在中间一排：

- 第 1 波：刀兵 x1
- 第 2 波：骑兵 x1
- 第 3 波：曹操 x1

### 第 2 关

- 第 1 波：刀兵 x2，分别出现在第 1、2 排。
- 第 2 波：骑兵 x2，分别出现在第 1、2 排。
- 第 3 波：刀兵 x3，分别出现在第 1、2、3 排；曹操出现在第 2 排刀兵后面。

后续再扩展到更多关卡、多波组合与随机生成。
