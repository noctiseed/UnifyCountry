# Battle Prototype v001

## Game Type

三国题材、2D 横版、回合制、卡牌上阵、左右战线对抗。

## Board Layout

战斗主界面分为左右两侧：

- 左侧：玩家友方单位区域。
- 右侧：敌方单位区域。
- 底部：玩家手牌区域与结束回合按钮。
- 玩家大本营位于友方阵地上方居中位置，并展示生命值。

友方阵地为 3 排 x 5 列的伪 2.5D 横向错位棋盘。

敌方阵地为 3 排长条队列，不再受 5 列格子上限限制。同一排内如果当前敌人数量可以正常摆下，则按常规间距横向展开；如果数量过多，则压缩单位间距并形成层叠遮挡。队列前方单位层级更高，会覆盖后方单位的一部分。

每一排独立结算前线：

- 友方单位从右向左排列，每排最右侧单位优先承伤。
- 敌方单位按长条队列从前到后排列，每排最前方单位优先承伤。
- 新敌方波次直接追加到对应排队列末尾；如果上一波同排仍有残留单位，后续单位继续排在其后方。
- 死亡结算后，友方每排向右补位；敌方每排保持队列顺序，移除死亡单位后后续单位向前补位。
- 玩家可以将手牌放入任意友方空格。
- 玩家可以在同一排的两个单位之间插入新单位，或在该排最右侧单位右边插入新单位。
- 不允许在两排之间插入单位。

## Card Data

当前卡牌数据拆分为：

- `cards_v001.csv`：卡牌通用信息，例如卡牌类型、费用、阵营、势力、稀有度、卡图 ID。
- `units_v001.csv`：单位牌信息，例如单位编号、英雄 / 普通兵种 / Boss、血量、攻击力、角色定位、标签和技能效果 ID。
- `effects_v001.csv`：技能效果信息，例如触发时机、效果类型、目标规则和数值。
- `player_starting_deck_v001.csv`：玩家初始牌库，每行配置一张卡的初始数量与牌组规则。
- `battle_001_waves_v001.csv`：战斗波次配置，按关卡、波次和前中后军分别指定敌方单位。

当前卡牌类型包括：

- `Unit`：单位牌，玩家单位可以上阵到友方阵地，敌方单位通过波次生成。
- `Skill`：计谋牌，玩家点击手牌后进入施法状态，根据目标规则选择单位、整排或无目标立即释放。

普通兵种的卡牌阵营默认为 `Neutral`，作为单位模板复用：同一张普通兵种卡可以由玩家上阵为友方单位，也可以由敌方波次生成为敌方单位。英雄、Boss 和计谋牌仍按卡牌阵营区分归属。Boss 本质上仍是 `Unit` 卡，但 `unit_type` 使用 `Boss`，用于承载敌方首领版本的独立身板、技能和战斗结算身份。

## Unit Stats

当前单位包含：

- 血量
- 当前攻击力
- 费用
- 类型：英雄 / 普通兵种 / Boss
- 阵营：友方 / 敌方
- 技能效果
- 运行时状态：护盾、护甲、免疫攻击次数、复苏层数、灼烧层数、荆棘层数、攻击力变化、最大血量变化、单次伤害上限
- 护盾层数：次数型 Buff。受到敌方单位攻击时，优先消耗 1 层护盾并取消本次攻击伤害。
- 护甲点数：常驻型 Buff。受到敌方单位攻击时，每点护甲抵挡 1 点伤害，并消耗对应点数；护盾优先于护甲消耗。
- 荆棘层数：常驻型 Buff。受到敌方单位攻击时，使攻击者受到等同于当前荆棘层数的伤害；即使本次攻击被护盾、免疫或护甲抵挡，也会触发荆棘。

当前英雄费用：

- 刘备：1
- 关羽：2
- 张飞：2
- 赵云：2
- 马超：2
- 简雍：1
- 曹操：2
- 夏侯惇：2
- 曹仁：2

伤害规则：

```text
若目标拥有护盾层数，先消耗 1 层护盾并取消本次敌方攻击
若目标拥有免疫攻击次数，先消耗 1 次免疫并取消本次伤害
若目标拥有单次伤害上限，则本次伤害不超过该上限
若目标拥有护甲点数，则护甲按点数抵挡结算后伤害并消耗
目标当前血量 -= 护甲抵挡后的剩余伤害
目标当前血量 <= 0 时死亡
```

当前直接伤害分为攻击来源伤害和无来源伤害：普通攻击、英雄技能伤害和计谋牌伤害都会受到 `BeforeDamaged` 伤害上限影响，并且在目标实际扣血后仍存活时触发 `OnDamaged` 受击后效果；如果该次伤害直接击杀目标，则不触发 `OnDamaged`。无来源计谋牌伤害不会消耗护盾 / 免疫攻击次数 / 护甲。

复苏规则：

- 复苏是层数型 Buff。
- 玩家回合战斗结算中，`OnTurnEnd` 触发后、死亡移除和补位前，存活单位若拥有复苏，则触发一次复苏。
- 回合结束 Buff 结算时，灼烧优先于复苏；如果单位死于灼烧，则不会触发复苏。
- 灼烧伤害可以被护盾、免疫攻击次数和护甲抵挡；护盾或免疫会抵挡整次灼烧，护甲按点数抵挡剩余灼烧伤害。
- 每次触发时，按触发前复苏层数恢复生命，然后复苏层数减少 1。
- 单位已经死亡并被移出阵地时，不会触发复苏。

## Skill Rules

当前英雄技能采用第一版轻量触发机制：

- `OnPlay`：单位上阵或敌方波次生成时触发。
- `OnAttack`：单位攻击时触发。
- `BeforeDamaged`：单位受到伤害前触发，用于伤害修正。
- `OnDamaged`：单位受到伤害后触发。普通攻击、英雄技能伤害和计谋牌伤害都会触发；只有实际扣除生命且目标受击后仍存活时才触发。
- `OnTurnStart`：玩家正式回合开始时，对场上存活的玩家单位触发。
- `OnTurnEnd`：玩家点击结束回合后的战斗结算中，我方反击结束后、回合末 Buff 结算前，对场上存活的玩家单位触发。

当前英雄技能：

- 刘备「昭烈仁德」：每回合开始时，使当前队列所有友方单位最大生命值 +1 并恢复 1 点生命，获得 3 层复苏。
- 关羽「武圣」：攻击时，对当前目标额外造成 2 点伤害。
- 张飞「据水断桥」：每回合结束时，获得 2 层荆棘。
- 赵云「龙胆」：每回合开始时，获得 5 点护甲。
- 马超「铁骑横扫」：攻击替换为对敌方当前排所有单位造成 2 点伤害。
- 简雍「论客」：存活在场时，每个玩家正式回合开始额外抽 1 张牌。
- 曹操「魏武号令」：上阵时，同排所有友方单位攻击 +1。
- 夏侯惇「刚烈」：每次受到普通攻击、英雄技能伤害或计谋牌伤害后，若夏侯惇仍存活，自身攻击力 +1；若该次伤害直接使其死亡，则不触发。
- 曹仁「固守」：每次受到伤害时，最多只受到 4 点伤害。

单位 token 会在血条上方显示攻击图标和 Buff 图标，鼠标悬停可查看说明。护盾、护甲、免疫、复苏、灼烧、荆棘均以 Buff 图标展示，避免与状态短文本重复。

单位 token 状态短文本仅用于少量非 Buff 型规则，例如单次伤害上限：

```text
限4
```

## Plan Card Rules

当前计谋牌均为玩家 `Skill` 卡，释放后进入弃牌堆：

- 滚石（1 费）：选择敌方单体，造成 3 点伤害。
- 齐射（1 费）：选择敌方一整排，对该排所有敌方单位造成 1 点伤害。
- 疗伤（1 费）：选择友方单体，恢复 2 点生命，并获得 2 层复苏。
- 强化（1 费）：选择友方单体，攻击 +2，最大血量 +2，并恢复 2 点生命。
- 加固（1 费）：选择友方单体，获得 1 层护盾。
- 火攻（2 费）：选择敌方单体，造成 3 点伤害，并施加 2 层灼烧。
- 火箭（2 费）：选择敌方一整排，对该排所有敌方单位造成 1 点伤害，并施加 2 层灼烧。
- 斩杀（1 费）：选择敌方单体，造成 1 点伤害；若该伤害直接击杀目标，获得 1 点当前可用费用。
- 草船借箭（1 费）：无目标，立即抽 2 张牌。

计谋牌目标规则：

- `EnemySingle`：需要选择一个存活敌方单位。
- `EnemyRow`：需要选择一排至少有存活单位的敌方阵地。
- `AllySingle`：需要选择一个存活友方单位。
- `NoTarget`：不需要选择目标，点击后立即释放。

## Deck Rules

- 刘备是主公卡，初始牌库有且只有 1 张，后续奖励中不会再出现。
- 除刘备外，其他玩家可获得卡牌都可以通过奖励重复拿多张，包括英雄、普通兵种和计谋牌。
- 玩家初始牌库包含：刘备、关羽、张飞各 1 张；盾牌兵、弓箭手各 3 张；滚石、疗伤、加固各 1 张。
- 初始回合抽 5 张牌。
- 初始手牌优先从英雄卡库中随机抽取英雄卡。
- 当英雄卡数量大于 5 张时，随机选择 5 张英雄卡进入初始手牌。
- 当英雄卡数量小于或等于 5 张时，所有英雄卡进入初始手牌，剩余手牌位从抽牌堆补足。
- 初始回合结束时，未使用的手牌进入弃牌堆；抽牌堆中剩余的英雄卡也进入弃牌堆。
- 后续回合每回合抽 3 张牌，不再触发英雄卡必定进入手牌的规则。

## Turn Flow

```text
InitialPrepare
  玩家抽到 5 张初始手牌，英雄卡优先进入手牌
  玩家初始准备回合拥有 5 点费用
  玩家可以出牌

PrepareEnd
  玩家点击结束回合，准备阶段结束并进入第 1 回合

TurnStart
  当前回合对应敌方波次出现
  敌方单位站场，但不触发攻击
  玩家费用恢复到 3 点，抽 3 张牌
  场上存活的玩家单位触发 OnTurnStart 效果
  玩家继续操作，可以上阵单位或释放计谋牌

PlayerEndTurn
  玩家点击结束回合，进入战斗结算

EnemyAttack
  敌方攻击按前军、中军、后军顺序结算，也就是从屏幕下方一排开始，逐排结算到屏幕上方
  每一排内先结算敌方攻击，随后立刻结算该排友方反击，然后进入下一排
  敌方按排内队列从前到后依次攻击，每个单位攻击一次
  优先攻击同排最右侧友方单位；同排没有友方单位时攻击玩家大本营
  攻击过程中会结算相关技能、护盾、免疫、伤害上限、护甲和荆棘

PlayerAttack
  友方反击不再等待所有敌方排攻击完毕，而是在当前排敌方攻击结束后立即进行
  友方按排从右到左依次攻击，每个单位攻击一次
  优先攻击同排最前方敌方单位；同排没有敌方单位时不造成伤害
  攻击过程中会结算相关技能、护盾、免疫、伤害上限、护甲和荆棘

TurnResolve
  场上存活的玩家单位触发 OnTurnEnd 效果
  存活单位结算回合结束型 Buff，先结算灼烧，再结算复苏
  结算死亡与胜负

NextTurn
  进入下一回合的 TurnStart
```

## Combat Presentation

当前原型已经接入第一版 DOTween 战斗表现：

- 单位攻击单位时，攻击者会临时提升到顶层动画层，移动到目标面前攻击后回到原站位，避免跨阵地移动时被另一侧阵地遮挡。
- 单位攻击玩家大本营时，保留短距离前冲表现。
- 攻击结算后，所有在本次攻击过程中实际扣血的对象都会播放受击抖动、受击闪光和伤害飘字。
- 荆棘反伤、额外伤害、替代攻击以及其他攻击过程中触发的连带扣血，都会通过全场血量变化对比触发对应受击反馈。
- 死亡单位会继续沿用死亡淡出和补位动画。
- 临时动效对象会在 UI 销毁时自动停止对应 DOTween，避免死亡、补位或界面刷新期间残留动画访问已销毁对象。

## Level Rules

当前原型支持关卡概念。波次配置中的 `row_1_card_ids`、`row_2_card_ids`、`row_3_card_ids` 分别对应后军、中军、前军；也就是屏幕上方、中间、下方三排。同一排内多个卡牌 ID 使用 `|` 分隔，并按配置顺序追加到该排敌方长条队列末尾。当前弓箭手暂不使用远程机制，按普通同排单位参与战斗。

### 第 1 关

第 1 关为中军防御战教学，敌人默认出现在中军：

- 第 1 波：中军，盾牌兵 x1。
- 第 2 波：中军，刀兵 x1。
- 第 3 波 Boss：中军，盾牌兵 x1、刀兵 x1、张梁 x1。张梁为防御型小 Boss，25 血 / 3 攻；登场时同排敌方单位获得 3 点护甲，张梁自身额外获得 5 点护甲，因此张梁合计获得 8 点护甲。

### 第 2 关

- 第 1 波：前军，刀兵 x1、弓箭手 x1。
- 第 2 波：后军，盾牌兵 x1、弓箭手 x1。
- 第 3 波 Boss：中军，盾牌兵 x1、刀兵 x1、张宝 x1。张宝为妖火型小 Boss，10 血 / 3 攻；登场时对同排敌对单位施加 3 层灼烧，自身获得 1 层护盾。

### 第 3 关

- 第 1 波：后军，弓箭手 x1；中军，盾牌兵 x1；前军，刀兵 x1、骑兵 x1。
- 第 2 波：后军，骑兵 x1；中军，刀兵 x1、弓箭手 x1；前军，盾牌兵 x1。
- 第 3 波 Boss：后军，弓箭手 x1、刀兵 x1；中军，张角 x1；前军，盾牌兵 x1、刀兵 x1。张角为最终 Boss，40 血 / 3 攻；登场时所有黄巾方单位获得 2 层复苏，张角自身获得 2 层护盾；每回合开始时，对张角当前排的玩家单位施加 1 层灼烧。

后续再扩展到更多关卡、多波组合与随机生成。
