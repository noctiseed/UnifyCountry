# Battle Prototype v001

## Game Type

三国题材、2D 横版、回合制、卡牌上阵、左右战线对抗。

## Board Layout

战斗主界面分为左右两侧：

- 左侧：玩家友方单位区域。
- 右侧：敌方单位区域。
- 底部：玩家手牌区域与结束回合按钮。

友方单位从右向左排列，最右侧单位优先承伤。敌方单位镜像布局，从左向右排列，最左侧单位优先承伤。

## Unit Stats

第一版单位只包含：

- 血量
- 攻击力
- 费用
- 类型：英雄 / 普通兵种
- 阵营：友方 / 敌方

伤害规则：

```text
目标当前血量 -= 攻击方攻击力
目标当前血量 <= 0 时死亡
```

## Deck Rules

- 英雄卡在牌库中最多只能有 1 张。
- 普通兵种可以重复。
- 玩家初始牌库包含：刘备、关羽、张飞各 1 张；盾牌兵、弓箭手各 3 张。
- 英雄卡必定出现在第一回合手牌中。
- 每回合抽 3 张牌。

## Turn Flow

```text
InitialPrepare
  玩家抽到第一回合手牌，英雄卡必定出现
  玩家可以出牌

PlayerEndTurn
  玩家点击结束回合

WaveSpawn
  当前回合对应敌方波次出现

EnemyAttack
  敌方从左到右依次攻击，每个单位攻击一次

PlayerAttack
  友方从右到左依次攻击，每个单位攻击一次

TurnResolve
  结算死亡与胜负

NextTurn
  玩家抽 3 张牌并继续操作
```

## Prototype Waves

```text
第 1 波：刀兵 x1
第 2 波：骑兵 x1
第 3 波：曹操 x1
```

第一版先按这个固定场景实现，后续再扩展到每波两个敌对单位、多波组合与随机生成。
